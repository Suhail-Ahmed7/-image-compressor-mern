# 🖼️ Image Processing Web App (MERN Stack)

A powerful full-stack web application that allows users to **resize**, **compress**, and **convert images** directly from the browser. Built with the **MERN stack** (MongoDB, Express.js, React.js, Node.js), this tool is designed for speed, usability, and real-world utility.
---

## 🚀 Features

* ✂️ **Image Resizing**
  Resize images to custom dimensions with a simple and responsive UI.

* 📦 **Image Compression**
  Reduce image file size while maintaining high quality.

* 🔄 **Image Format Conversion**
  Seamlessly convert images between formats (JPG, PNG, WEBP, etc.).

* 🔐 **Authentication System**

  * Only logged-in users can download processed images
  * Secure token-based authentication (JWT)
  * Redirects unauthenticated users to login with helpful messages

* ⚙️ **Real-Time Processing**
  Fast and optimized image processing using Node.js and Sharp.

* 🧠 **User-Friendly Experience**
  Intuitive UI, responsive design, and clear feedback to guide the user.
---

| Layer           | Technology           |

| **Frontend**    | React.js, CSS        |

| **Database**    | MongoDB (Mongoose)   |

---
## 💡 How It Works

1. Users register or log in to access image tools.
2. Choose a tool (Resize / Compress / Convert).
3. Upload an image and customize settings.
4. Click "Download" to get the result.
5. If not logged in, user is redirected to login page with a prompt.
---
## 🔐 Security Highlights

* JWT-based authentication with protected routes
* Backend validation to ensure only authorized downloads
* Clean error handling and helpful feedback messages
